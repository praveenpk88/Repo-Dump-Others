## Brand direction (decided)
- **Branding: il Mercato Centrale.** The manager's draft used "La Pizza Napoletana by Samuele Ferro" with an LPN stamp; that is not the direction now.
- **Look: the il Mercato promo/menu style**, not dark or "designed". The user rejected the dark version as "not Mercato".
  - Red `#C40001` on cream `#FDFBEF` / `#F8F1DF`.
  - Chunky title font: **Lilita One**, condensed with CSS `transform: scaleX(.84–.86)`. It is a close match for their Canva font.
  - Body text: **Fraunces** serif. Names in bold red, prices written "Margherita $22".
  - Red/cream checkered bands, light-blue oval `#B9CBD6` behind titles, dot grids, "× × × ×" marks, round red price badges.
  - Logo: `pizza-menu/brand/il-mercato-logo.png`. It was cut from an old menu, so ask il Mercato for a vector or PNG logo before final print.

## Repo and workflow
- Repo `praveenpk88/Repo-Dump-Others`, branch **`ccr-71e69816-b4crzy`**. Commit and push after every change. A stop hook complains about untracked files.
- Each design is HTML/CSS generated by a Node script and rendered with **Playwright + Chromium**, which is preinstalled (`require('playwright')`).
- Outputs are PDF (print, sized in mm) and PNG. Send results to the user with SendUserFile and look at renders before sending.
- Photos are cut from images with small Python scripts (`cut_*.py`, run with `python3 -I`).
- Caption `.txt` files must be saved as **UTF-8 with BOM**. Without it the user's app showed emojis as Chinese characters.
