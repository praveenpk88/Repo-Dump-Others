# Repo-Dump-Others

This repository contains the Task 3 high-level flowchart assets for Programming Fundamentals Assignment 1.

Included files (see flowcharts/task3/):
- task3_flowchart_full.svg: A3-style, color-coded image of the full flowchart.
- task3_flowchart_full.dot: Graphviz source for the same flow.

How to get a Visio (.vsdx) file quickly
1) Open the SVG in Microsoft Visio: File → Open → select task3_flowchart_full.svg.
2) Save As → Visio Drawing (*.vsdx).

Alternative (if you want to edit the graph structure):
- Open the DOT file in yEd (free), then Export → Visio VDX, and open the .vdx in Visio to Save As .vsdx.
